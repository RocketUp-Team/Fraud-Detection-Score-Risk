# Documentation Consistency Report

## Source-of-truth policy

For data facts, use one official bundle containing `manifest.json`, `verification_report.json`, `feature_order.json`, `model_ready_schema.json` and generated metrics. For runtime behavior, source code and a successful container smoke test outrank prose. `docs/REPORT_FACTS.json` records the current mixed-evidence state and intentionally uses `null` where proof is absent.
