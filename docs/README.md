# Project Documentation

This directory contains the as-built documentation and academic report for the
Fraud Detection and Risk Scoring System.

## Main deliverables

- [`SYSTEM_DOCUMENTATION.md`](SYSTEM_DOCUMENTATION.md) — detailed description of
  the current data, model, API, frontend, deployment, testing, and operational
  architecture.
- [`PROJECT_REVIEW_REPORT.md`](PROJECT_REVIEW_REPORT.md) — evidence-based review,
  implementation status, key findings, severity assessment, and remediation
  roadmap.
- [`API_CONTRACT.md`](API_CONTRACT.md) — implementation-aligned HTTP API
  contract and current client synchronization gaps.
- [`latex/report.pdf`](latex/report.pdf) — compiled thesis-style report following
  the supplied FPT University MSE template.
- [`latex/report.tex`](latex/report.tex) — LaTeX entry point.
- [`latex/README.md`](latex/README.md) — metadata, build, and submission
  instructions.

## Reference template

The report structure and page format were derived from
`3. Thesis_Template_MSE_FPT University.pdf`. Student, supervisor, degree, and
submission metadata remain explicit placeholders in `latex/metadata.tex` and
must be completed before formal submission.
