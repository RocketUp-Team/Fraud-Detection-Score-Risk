\section*{AI Assistance and Verification Disclosure}

In accordance with academic integrity standards, the project team discloses the responsible use of Artificial Intelligence (AI) tools during initial project planning, code drafting, and documentation formatting.

The team explicitly affirms human ownership of the final work. AI-suggested code snippets, architectural ideas, and documentation drafts were inspected, edited, refactored, and verified by team members before inclusion. The Apache Spark ETL scripts, machine-learning estimators, isotonic calibration models, FastAPI endpoints, and React components were checked against the available runtime and test evidence rather than being accepted solely because an AI system proposed them. The metrics, PR-AUC and ROC-AUC values, holdout results, checksums, and promotion-gate evidence reported in this document are tied to recorded execution artifacts and verified data contracts. This disclosure describes assistance and review; it does not replace the team's responsibility for the accuracy, originality, and academic integrity of the submitted report.
