\section*{AI Assistance and Verification Disclosure}

In accordance with academic integrity standards, the project team discloses the responsible use of Artificial Intelligence (AI) tools during initial project planning, code drafting, and documentation formatting.

The team explicitly affirms that:
\begin{itemize}
  \item \textbf{Human Ownership and Verification}: All AI-suggested code snippets, architectural ideas, and documentation drafts were thoroughly inspected, modified, refactored, and verified by team members.
  \item \textbf{Empirical Runtime Validation}: All Apache Spark ETL scripts, machine learning estimators, isotonic calibration models, FastAPI REST endpoints, and React UI components were independently executed, unit-tested, and verified via automated test suites.
  \item \textbf{Data Integrity}: All metrics, PR-AUC/ROC-AUC values, holdout evaluation results, checksums, and promotion gate evidence in this report are derived strictly from empirical runtime execution logs and verified data contracts.
\end{itemize}
