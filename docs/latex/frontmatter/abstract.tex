\addcontentsline{toc}{chapter}{Abstract}

This thesis presents an academic fraud risk scoring workflow for the IEEE-CIS
dataset. Apache Spark performs typed ingestion, transaction--identity joining,
quality auditing, chronological leakage-controlled processing, feature
engineering, and Parquet handover. Python training compares Logistic Regression,
LightGBM, XGBoost, and CatBoost after the Spark-to-pandas boundary. The scoring
package records preprocessing mappings, calibration state, thresholds, model
metadata, and local explanations for an in-process FastAPI service with a React
review interface. The current CatBoost balanced candidate achieves validation
ROC-AUC 0.9081 and PR-AUC 0.5806, with holdout ROC-AUC 0.8781 and PR-AUC 0.4266.
Because holdout PR-AUC is below the promotion target, the candidate remains
not promoted and the configured serving default is unchanged. Offline--online
feature mismatch, single-node training, fallback behaviour, and incomplete
security and monitoring controls limit the result to an auditable academic
demonstration rather than a production-readiness claim.
