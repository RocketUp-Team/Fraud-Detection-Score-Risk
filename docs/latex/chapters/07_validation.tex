\section{Consolidated limitations}

\begin{enumerate}
  \item \textbf{Reproducibility}: Local MLflow tracking and single-node pandas training.
  \item \textbf{Policy Alignment}: Runtime backend risk bands decoupled from offline threshold optimization.
  \item \textbf{Offline-Online Parity}: Real-time feature store for historical aggregates not implemented.
  \item \textbf{Operational Controls}: Fail-open fallback heuristic and in-memory background jobs.
  \item \textbf{Security \& Governance}: Authentication, role-based authorization, and durable audit logs absent.
\end{enumerate}
