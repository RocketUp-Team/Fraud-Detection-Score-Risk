\chapter{Background and Related Work}
\label{chap:background}

\section{Imbalanced temporal ranking}

Fraud detection is framed as binary temporal ranking on rare positive cases (fraud rate $\approx$ \val{3.5\%}). Chronological splitting along \texttt{TransactionDT} preserves temporal order and prevents lookahead leakage.

\section{IEEE-CIS dataset structure}

The dataset contains \val{590,540} training transactions and optional identity records \parencite{ieeecis2019}. Preserving transaction row authority via LEFT JOIN prevents data loss while capturing missingness indicators.

\section{Technology boundary}

Architecture operates via \textbf{distributed Spark data preparation with single-node Python estimator training}. CatBoost, LightGBM, XGBoost, and Logistic Regression are evaluated, using TreeSHAP for feature attribution \parencite{lundberg2017shap}.
