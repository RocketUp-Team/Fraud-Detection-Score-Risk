\chapter{Application and Deployment}
\label{chap:application}

\section{Integrated serving architecture}

The application operates as an \textbf{in-process model-serving modular monolith}. FastAPI imports the scoring package directly, persisting scored transactions in PostgreSQL/SQLite and serving a React dashboard.

\section{Scoring and review workflow}

The backend returns probability, risk score (\val{0}--\val{100}), risk band, decision, and TreeSHAP attributions. Scored transactions and human analyst reviews are stored as distinct database entities.

\section{Deployment boundary}

Docker Compose orchestrates preprocessing, training, backend, and React UI profiles, mounting processed Parquet artifacts into the backend container.
