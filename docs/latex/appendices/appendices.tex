\chapter{Reproducible Runbook}
\label{app:runbook}

\section{Raw data placement}

\begin{lstlisting}
data/data/ieee-fraud-detection/
  train_transaction.csv
  train_identity.csv
  test_transaction.csv
  test_identity.csv
  sample_submission.csv       # optional
\end{lstlisting}

\section{Preprocessing}

\begin{lstlisting}[language=bash]
docker compose -f docker-compose.preprocessing.yml build
docker compose -f docker-compose.preprocessing.yml run --rm preprocess
docker compose -f docker-compose.preprocessing.yml run --rm verify-processed
\end{lstlisting}

If a completed Spark export lacks a finalized manifest:

\begin{lstlisting}[language=bash]
python -m pipeline.processed_contract \
  --output-dir data/processed/ieee_cis_fraud_risk
python -m pipeline.verify_processed_data \
  --output-dir data/processed/ieee_cis_fraud_risk
\end{lstlisting}

\section{Model training}

\begin{lstlisting}[language=bash]
bash scripts/run_official_full.sh
\end{lstlisting}

The official workflow runs preprocessing, contract validation, baseline,
comparison, tuning, calibration, threshold analysis, holdout evaluation,
packaging, checksum generation, and the promotion gate. The current official
decision is \texttt{not\_promoted}; the serving configuration remains unchanged.
Holdout evaluation must occur only after model and policy selection are fixed.

\section{Application}

\begin{lstlisting}[language=bash]
docker compose up --build
\end{lstlisting}

Then open:

\begin{itemize}
  \item dashboard: \url{http://localhost:5173};
  \item API documentation: \url{http://localhost:8000/docs};
  \item optional Adminer: \url{http://localhost:8081}; select the
  \texttt{PostgreSQL} system, then use the configured database credentials.
\end{itemize}

\section{Local development}

\begin{lstlisting}[language=bash]
# Terminal 1
cd backend
uv sync --frozen
uv run uvicorn fraud_backend.main:app --reload

# Terminal 2
cd frontend
npm ci
npm run dev
\end{lstlisting}

\section{Rollback}

\begin{lstlisting}[language=bash]
FRAUD_MODEL_SERVING_VERSION=v1
\end{lstlisting}

Restart the backend and verify \texttt{/meta} before accepting traffic.
The rollback setting is a configuration path, not evidence that V1 has been
validated as the current champion in the official snapshot.
